# Shadow-Chase
Shadow Chase é um jogo de terror e sobrevivência em visão top-down, ambientado em uma masmorra sombria e repleta de mistérios. Preso em um lugar onde a escuridão domina cada corredor, o jogador precisa explorar o ambiente, coletar recursos e encontrar a saída enquanto é perseguido por uma criatura aterrorizante que se esconde nas sombras.
